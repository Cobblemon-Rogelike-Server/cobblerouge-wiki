# 홈 콘셉트 일러스트

`islands.webp`는 2026-10-26 이 위키의 홈을 위해 생성한 AI 콘셉트 일러스트입니다. 농장·오두막에서 다리를 건너 숲속 던전으로 향하는 떠 있는 섬을 표현합니다. 게임의 실제 스크린샷이나 구현된 맵을 표현한 자료가 아닙니다. 홈의 대체 텍스트와 그림 아래 설명에도 이 구분을 표시합니다.

원본 게임 이미지 692장의 Base64 묶음과 복원 경로는 변경하지 않았습니다. 이 파일은 별도의 편집 일러스트이며 빌드가 `dist/assets/editorial/`로 복사합니다. 이미지 내 텍스트에 의존하지 않고 제목·버튼·안내는 실제 HTML로 제공합니다. 그림이 로드되지 않아도 시작 안내와 탐색을 이용할 수 있습니다.
