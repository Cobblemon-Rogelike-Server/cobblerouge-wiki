# CobbleRouge 위키

던전 진행과 탐험단, 작물 56종·재배 도구·전용 나무·건축 재료를 안내하는 한국어 게임 위키입니다. 문서 114개와 원본 게임 PNG 692장을 제공합니다. Python 표준 라이브러리로 만드는 정적 사이트이며 외부 폰트·이미지 CDN·추적 스크립트는 사용하지 않습니다.

## 화면과 탐색

홈에서 시작 안내, 네 단계의 던전 진행 순서, 분야별 문서를 찾을 수 있습니다. 실제 게임 이미지와 읽기 쉬운 목록·표를 사용합니다. AI 생성 배경과 장식용 슬로건은 사용하지 않습니다.

- 상단 검색은 이름·아이템 ID·본문을 검색합니다. `Ctrl K` 또는 macOS의 `⌘ K`로 검색창에 이동합니다. 한글 입력이 끝난 뒤 검색하며 분류별로 결과를 좁힐 수 있습니다.
- 긴 문서는 자동 목차와 절 바로가기를 제공합니다. 모바일 목차는 접을 수 있고, 표는 본문과 별도로 가로 스크롤할 수 있습니다.
- 문서의 이전·다음·관련 문서와 링크 복사를 제공합니다. 체크박스·문서 저장·최근 본 문서·읽기 진행률·예상 읽기 시간은 제공하지 않습니다.
- 개인 읽기 상태를 기록하지 않습니다. 이전 버전의 `cobblerouge-wiki:reading:v1` 키만 정리하고 다른 브라우저 데이터는 변경하지 않습니다. 저장소 접근이 차단돼도 위키를 이용할 수 있습니다.
- 이전 `#/saved` 주소는 홈으로 이동합니다. 문서·분류·검색 주소와 기존 목차 절 주소는 유지합니다. 런처 검색 연결은 `#/search?q=유전자` 형식입니다.
- GitHub의 오류 제보 링크는 새 이슈 작성 화면으로 연결하며 GitHub 로그인이 필요합니다.

## 로컬 실행

빌드는 Python 3.10 이상만 필요합니다. npm 패키지 설치나 비공개 저장소 인증이 필요하지 않습니다.

```sh
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

http://localhost:8000 에서 확인합니다. `dist/`는 생성 결과이며 Git으로 관리하지 않습니다. 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

## 검증

브라우저 검사는 Node.js 24 이상과 Chrome/Chromium을 사용합니다. 아래는 Linux 예시이며 `CHROMIUM_PATH`에 설치된 브라우저 경로를 지정합니다.

```sh
python3 scripts/build.py
node --check app.js
WIKI_UI_ARTIFACTS=/tmp/wiki-check CHROMIUM_PATH=/usr/bin/chromium node scripts/check-ui.mjs
python3 scripts/check-external-links.py --artifacts /tmp/wiki-check
```

- 빌드: 문서 ID 중복, 작물 56종, 원본 이미지 692장과 모든 문서 이미지 참조를 검증합니다.
- 브라우저: 모든 문서와 화면에서 생성한 링크를 수집하고, 서로 다른 내부 목적지마다 실제 링크를 따라가 문서 제목·목차 절을 확인합니다. 본문 외에도 메뉴·목록·검색·이전/다음·관련 문서를 포함합니다. 라이선스 파일도 실제 응답을 검사합니다.
- 동작: 모든 재배 환경 필터와 검색 분류, 한글 입력·검색 제출·단축키, 링크 복사·복사 권한 거부 시 안내, 모바일 메뉴·목차, 뒤로/앞으로 이동, 데이터 불러오기 실패·재시도를 확인합니다.
- 제거 검증: 기존 읽기 기록 정리, 다른 저장 데이터 보존, 저장소 차단 시 동작, 제거된 UI가 다시 나타나지 않는 것을 확인합니다.
- 화면: 320·390·768·1024·1440px의 가로 넘침, 원본 이미지 로드, 주요 글자·링크의 대비, 배포 CSP와 JavaScript 예외를 확인합니다. 데스크톱·모바일 화면 PNG를 남깁니다.
- 외부 연결: 수집한 외부 URL을 인증 없이 실제로 요청합니다. 정상 응답, 예상된 GitHub 로그인, 잘못된 주소, 접근 제한·네트워크 차단으로 확인하지 못한 연결을 구분합니다. 미확인을 성공으로 표시하지 않습니다.

결과는 `link-audit.json`과 `external-links.json`에 출발 화면·링크 이름·목적지·검증 상태와 사유를 기록합니다. `.github/workflows/check.yml`이 push·PR에서 같은 검사를 실행하고 보고서·화면을 7일 보관합니다. 외부 서비스의 접근 제한으로 미확인이 있으면 외부 링크 검사는 실패하며 보고서에서 원인을 확인할 수 있습니다.

## Vercel 배포

저장소를 Vercel에 연결하고 Framework Preset을 **Other**, Root Directory를 저장소 루트로 지정합니다. `vercel.json`이 빌드 명령 `python3 scripts/build.py`와 출력 디렉터리 `dist`를 설정합니다. 환경 변수나 데이터베이스는 필요하지 않습니다. 기존 Git 연동에서 `main` 변경은 자동 배포됩니다. 별도 SPA 리라이트는 필요하지 않습니다.

## 내용과 이미지 수정

- `content/guides/`: 처음 시작하기·재배·섬 꾸미기 안내.
- `content/dungeon/`: 입장 준비, 여섯 종류의 방, 지도와 금화, 스텟, 전투, 정산·재접속·엔드리스 안내.
- `content/guild/`: 가입·직책·채팅·의뢰·금고·혜택·합동 탐사 등 탐험단 안내.
- `content/작물.md`, `전용_나무.md`, `목재_세트.md`, `장식_블럭.md`: 재배·성장·조합법과 원본 그림.
- `assets/images-*.json`: 원본 PNG를 손실 없이 보관하는 묶음. 빌드 시 `dist/images/`로 복원합니다.
- `app.js`, `styles.css`, `index.html`: 화면·검색·해시 라우팅. `scripts/build.py`는 문서 변환과 이미지 복원을 담당합니다.

그림을 갱신하려면 `python3 scripts/image_assets.py --extract-to work`로 원본을 추출하고, 경로를 유지한 채 수정한 뒤 `python3 scripts/image_assets.py --source work/images`로 묶음을 만드세요. 이 도구는 PNG를 재렌더링하지 않습니다. 마지막에 빌드와 브라우저 검사를 실행합니다. 3D 형태의 아이템 그림도 고정 PNG이며 회전형 뷰어가 아닙니다.
