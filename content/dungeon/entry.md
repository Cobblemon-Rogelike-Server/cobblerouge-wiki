# 입장 조건과 파티 준비

`/던전 입장`으로 입장 확인 화면을 열어 던전 종류, 배틀 모드와 파티 조건을 확인하세요.

## 입장할 수 있는 파티

- 파티가 비어 있으면 입장할 수 없습니다. 더블은 최소 두 마리가 필요합니다.
- 서버에 등급이 등록된 진화 계열만 입장할 수 있습니다.
- 파티의 코스트 합계가 내 코스트 스텟 이하여야 합니다.
- 같은 진화 계열을 중복해서 넣을 수 없습니다. 진화 단계가 달라도 같은 계열이면 중복입니다.
- 포켓몬의 지닌 도구는 빼 주세요.

`/포켓몬위키`에서 진화 계열의 등급과 코스트, 진화와 기술 정보를 확인할 수 있습니다. `/스텟`에서는 내 코스트를 봅니다.

## 입장하면 무엇이 바뀌나요?

기존 포켓몬은 PC에 보관되고, 던전에서는 각 계열의 기본 진화 형태를 레벨 5부터 키웁니다. 개체값, 이로치와 코스튬은 이어지며, 기존 레벨·노력치·특성·기술은 그대로 가져오지 않습니다. 던전 안에서도 진화할 수 있습니다.

플레이어의 가방·방어구·보조 손 아이템은 입장 시 보관됩니다. 던전에서 얻은 아이템으로 모험하고, 종료하면 보관했던 장비를 돌려받습니다.

## 명령어

| 명령어 | 기능 |
|---|---|
| `/던전 입장` | 기본 던전 입장 확인 |
| `/던전 입장 <타입> 싱글` | 타입과 싱글 지정 |
| `/던전 입장 <타입> 더블` | 타입과 더블 지정 |
| `/dungeon enter` | 영어 입장 명령어 |
| `/던전 나가기` · `/dungeon quit` | 진행 중인 모험 포기 |

> 던전의 파티와 포획한 포켓몬, 전리품은 모험 한 번에만 사용됩니다. 종료 시 가져갈 수 있는 것은 별도로 정산되는 종료 보상입니다.
