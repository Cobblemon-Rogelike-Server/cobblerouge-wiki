# 전투 화면과 배속, 음식

전투 상황판과 기술 미리보기를 활용하고, 필요한 순간에 음식으로 한 턴을 투자해 파티를 도와보세요.

## 전투 상황판

배틀 화면의 상황판 버튼을 누르면 내 편·상대 편 탭에서 능력치 랭크, 스피드, 일시적인 상태와 필드 상태를 확인합니다. 날씨, 필드, 장벽과 설치기, 남은 턴도 표시됩니다.

상대의 스피드는 최소~최대 범위로 표시될 수 있습니다. 더블처럼 비교할 내 포켓몬이 둘이면 하나의 속도 우열로 단정하지 않습니다.

## 기술 데미지 미리보기

기술 위에 마우스를 올리면 상대 HP 바에 예상 데미지 구간이 표시됩니다. 확률, 상대 정보와 전투 상황에 따라 실제 결과가 달라질 수 있으므로 확정 피해량으로 보지 마세요.

## 배속 설정

`/배속 3`은 내 배틀을 3배속으로 설정하고, `/배속 기본`은 서버 기본값을 따르게 합니다. 일부 교체·특성·승리 메시지의 속도는 서버 공통 설정을 따릅니다.

## 음식 사용

전투 중 사용하는 음식은 손에 들고 내 배틀 포켓몬을 우클릭합니다. 효과가 적용되면 그 포켓몬의 해당 턴 행동을 사용합니다. 사용할 수 없는 상황에서는 아이템과 턴이 소비되지 않습니다.

| 음식 | 전투 효과 |
|---|---|
| 구운 파 | 다음 공격 확정 급소 |
| 주빌라이프 머핀 | 공격·스피드 +1 |
| 파 감자 스튜 | 공격·방어 +1 |
| 힘야채 딥 | 공격과 방어 교환 |
| 맛있는꼬리 | 회피율 +2 |
| 사탕 사과 | 방어·특수방어 +1 |
| 사탕 열매 | 특수공격·특수방어 +1 |
| 포니기리 | 스피드 +3 |
| 음침한 차 | HP 1/4을 소모해 대타출동 |
| 회색시티 크런치 | 방어 +3 |
| 분노의 사탕 | HP 절반을 소모해 공격 최대 |
| 용암 쿠키 | 공격 +3 |
| 오래된 가토 | 이번 턴 버티기 |
| 성 아이스크림 | 특수방어 +3 |
| 미르시티 갈레트 | 페어리 단일 타입으로 변경 |
| 빅 말라사다 | 특수공격 +3 |
| 훈제꼬리 카레 | 공격·특수공격·스피드 +2, 방어·특수방어 −1 |
| 포켓 미끼 | 특수공격·특수방어·스피드 +1 |
| 포켓 스낵 | 모든 능력 +1 |
| 포켓 케이크 | 모든 능력 +2 |

모으모으밀크의 기존 HP 회복 기능은 그대로입니다. 음식마다 적용 조건이 있으므로 아이템 설명과 게임 안내를 확인하세요.
