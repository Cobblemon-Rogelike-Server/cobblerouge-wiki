# 직책과 단원 관리

탐험단에는 단장, 부단장, 단원 세 직책이 있습니다. 메뉴에서 현재 직책으로 할 수 있는 기능을 확인하세요.

| 직책 | 기본 권한 |
|---|---|
| 단장 | 모든 관리, 직책 변경, 단장 양도, 혜택 구매·해제, 해산 |
| 부단장 | 초대·가입 신청 관리, 단원 추방, 공지, 금고 출금 |
| 단원 | 탐험단 채팅, 활동 기여, 금고 입금과 공동 활동 참가 |

부단장을 추방하거나 다른 사람을 부단장으로 임명하는 일은 단장이 합니다.

## 관리 명령어

| 명령어 | 기능 |
|---|---|
| `/탐험단 초대 <닉네임>` | 초대 보내기 |
| `/탐험단 신청목록` | 가입 신청 검토 |
| `/탐험단 추방 <닉네임>` | 단원 추방 |
| `/탐험단 직책 <닉네임> <직책>` | 부단장·단원으로 변경 |
| `/탐험단 양도 <닉네임>` | 단장 양도 |
| `/탐험단 공지 <내용>` | 공지 변경 |
| `/탐험단 태그 <태그>` | 탐험단 태그 변경 |
| `/탐험단 탈퇴` | 현재 탐험단 나가기 |
| `/탐험단 해산` | 탐험단 해산 |

## 탈퇴와 장기 부재

탈퇴하거나 추방되면 기본 24시간 동안 다른 탐험단에 가입할 수 없습니다. 단장이 기본 14일 동안 접속하지 않으면 최근 접속한 부단장에게, 부단장이 없으면 최근 접속한 단원에게 자동으로 양도됩니다.

마지막 단원이 떠나면 탐험단이 해산되고 금고도 사라집니다. 단장의 해산과 메뉴의 탈퇴는 두 번 확인합니다.

> 시간과 정원 등은 서버 기본값입니다. 가입과 탈퇴 전에 현재 메뉴의 안내를 확인하세요.
